# Skill Routing

```text
TASK
  ↓
classify work
  ↓
select only relevant workflow/domain skills
  ↓
inspect repository evidence
  ↓
DISCOVER → REUSE → ADAPT → CREATE
  ↓
implement
  ↓
minimum sufficient verification
```

| Signal | Load |
|---|---|
| onboarding / local certification / reconciliation | `project-onboarding` |
| defect / unknown root cause | `bug-investigation` |
| non-trivial / cross-cutting / high-risk feature | `feature-planning` |
| meaningful diff / PR review | `code-review` |
| Mauro PHP/MySQL/JavaScript application | `mauro-coding-style` |
| Mauro CRUD framework/path | `mauro-crud` + `mauro-coding-style` |
| persistent MySQL change | `mysql-change-safety` |
| PHP AI/LLM integration | `php-ai-integration` |
| HTML/CSS/JS/UI/responsive work | `frontend-change` |

Search precedence: same module → same repository → same project/framework family → shared skill → new pattern.
