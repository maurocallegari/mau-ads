# frontend-change

```text
UI REQUEST
   ↓
find existing pattern
   ↓
minimal change
   ↓
preserve neighbors
   ↓
render / interaction check
   ↓
DONE
```

Use for HTML/CSS/JS/layout/actions/responsive work. Pair with `mauro-coding-style` on Mauro repositories and `mauro-crud` when CRUD-generated UI contracts are involved.

Verification stays proportional: a label change does not require a full regression suite.
